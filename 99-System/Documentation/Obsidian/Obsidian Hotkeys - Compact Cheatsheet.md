## ▶️ Navigation
| Action | Hotkey | Notes |
|---|---|---|
| **Quick switcher** | **Ctrl+O** | |
| **Command palette** | **Ctrl+P** | |
| **Go to next / previous tab** | **Ctrl+Tab** / **Ctrl+Shift+Tab** | Alt: **Ctrl+Page Down / Ctrl+Page Up** |
| **Go to tab #1–#9** | **Ctrl+1 … Ctrl+9** | **Ctrl+9** = last tab |
| **Focus tab group: left / right** | **Alt+←** / **Alt+→** | |
| **Navigate back / forward** | **Ctrl+Alt+← / Ctrl+Alt+→** | |
| **Open Graph view (global / local)** | **Ctrl+G** / **Ctrl+Alt+G** | |
| **Open Settings** | **Ctrl+,** | |
