# About Prompts

Prompt Library for creating, organizing, and maintaining reusable prompts in Obsidian.

---

## Folder Structure

| Folder | Purpose |
|---|---|
| **Workbench/** | Daily-use prompts you actively run |
| **Reference/** | Well-crafted prompts worth keeping for adaptation |
| **Fun/** | Roleplay, creative, entertainment |
| **Inbox/** | New captures, unsorted (QuickAdd target) |
| **Archive/** | Retired, deduped, stubs |

---

## Categories

7 categories for `prompt_category`: `writing`, `coding`, `business`, `education`, `productivity`, `creative`, `prompt-engineering`.

---

## Workflow

1. **Create** — QuickAdd lands new prompts in `Inbox/`
2. **Fill metadata** — title, category, status
3. **Write** — Instructions, examples
4. **Triage** — Move to Workbench, Reference, or Fun
5. **Retire** — Set status to archived, move to Archive
