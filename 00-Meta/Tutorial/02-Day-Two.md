## Story Context

Monday evening. Alex settles into their reading chair with a book they've been meaning to finish: **"Thinking in Systems: A Primer"** by Donella Meadows.

As they read about feedback loops and emergent behavior, something clicks - *"Wait, this is exactly what I saw with those trees yesterday!"*

---

## The Reading Session

### Progressive Summarization in Action

Alex reads Chapter 1 and highlights key passages:

> "A system is an interconnected set of elements that is coherently organized in a way that achieves something."

> "The behavior of a system cannot be known just by knowing the elements of which the system is made."

*"This is like the mycelium network,"* Alex realizes. *"Individual trees are just elements, but the network creates something more..."*

---

## Processing the Source

### Step 1: Create Source Note
Alex creates a source note for the book:
- Title, author, publication date
- Sets `source_type: book`
- Tags with `#📚source` and `#source/book`

### Step 2: Extract Key Insights
Using the 5-bullet TL;DR format:
1. Systems are interconnected elements with purpose
2. Feedback loops create self-reinforcing behavior
3. Emergence: the whole is greater than parts
4. Leverage points allow small changes → big effects
5. Systems produce counterintuitive results

### Step 3: Create Atomic Note
The compound growth insight is strong enough for its own note:

**"Compound Growth"** - Small, consistent additions create exponential results over time. Applies to learning, relationships, and knowledge systems.

### Step 4: Link to Yesterday's Observation
Alex adds a bidirectional link:
- Mycelium Networks ↔ Thinking in Systems
- Both demonstrate emergent system behavior

```

        ↓

        ↓

```
