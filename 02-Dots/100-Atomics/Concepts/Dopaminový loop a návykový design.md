## 🧠 One-liner
Dopaminový loop (trigger → anticipace → akce → odměna → opakování) je neurochemický základ návyků, gamifikace i závislostí.

## 🧩 Notes & Sketches
- Dopamin ≠ "hormon štěstí" — je to hormon **anticipace** a motivace
- Loop: cue/trigger → craving → response → reward (Nir Eyal: Hook Model)
- Variable ratio reinforcement (Skinner) — nejsilnější návykový vzorec (slot machiny, social media feeds)
- ADHD mozek: nižší bazální hladina dopaminu → hledání stimulace → vysvětluje prokrastinaci i hyperfokus
- Etický design: využít loop pro produktivní návyky, ne pro závislost
- Gamifikace v PKM: progress bars, XP, streak = dopaminové triggery pro knowledge work
