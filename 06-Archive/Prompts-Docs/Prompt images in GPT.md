## Japanese ink 

```
pt1) Transform this image into a Japanese ink wash-style painting (sumi-e), blending traditional brush techniques with digital stylization. Use a bold and limited palette — primarily black, white, and red — evoking the look of classic woodblock prints.

Stylize only the details that exist in the original image. Do not invent or add new elements that aren’t already present.
```

```
Pt2) If the photo is a landscape:
Highlight textures like waves, clouds, rocks, trees, smoke, or buildings using expressive ink lines and splashes. Add a large red sun or moon only if the composition allows it naturally. Use artistic brushwork and atmospheric depth without altering the layout.
```

```
Pt3) If the photo is a portrait:
Keep a strong visual likeness to the original person. Emphasize the mood with stylized brushstrokes, bold shadows, wind-blown hair, ink-drip effects, and dramatic lighting. Use the red sun or background splashes for visual weight, especially behind or beside the subject.
```
