# 🎨 Icon Reference & Color System

## Core System Icons

### Status Indicators
- ✅ **Completed/Active** - Green (success, healthy)
- ⚠️ **Warning/Attention** - Yellow (caution, moderate)
- 🚨 **Critical/Urgent** - Red (danger, immediate action)
- ⏸️ **Paused/Waiting** - Blue (neutral, paused)
- 📦 **Archived** - Gray (stored, inactive)

### Note Types
- 💡 **Atomic Notes** - Ideas and insights
- 🚀 **Projects/Efforts** - Action-oriented work
- 📚 **Sources** - External knowledge
- 🗺️ **MOCs** - Maps of content
- 📝 **Daily Notes** - Time-based reflection
- 👥 **Meeting Notes** - Discussion capture
- 🔧 **Tools/Resources** - Utilities and references

### Priority Levels
- 🔴 **P1 - Critical** - Immediate action required
- 🟠 **P2 - High** - Important, tackle soon
- 🟡 **P3 - Medium** - Standard priority
- 🟢 **P4 - Low** - When time allows
- ⚪ **P5 - Someday** - Future consideration

### Progress Indicators
- 🌱 **Seed** - Basic capture, minimal development
- 🌿 **Seedling** - Some expansion and structure
- 🪴 **Sapling** - Well-developed, good connections
- 🌲 **Evergreen** - Mature, stable content
- 🍓 **Fruit** - Ready to teach/share

### Time & Energy
- ⚡ **Quick** - <15 minutes
- 🟢 **Short** - 15-30 minutes
- 🟡 **Medium** - 30-90 minutes
- 🟠 **Long** - 90+ minutes
- 🔴 **Project** - Multi-session work

### Areas of Life
- 💼 **Work/Career** - Professional development
- 💪 **Health/Fitness** - Physical wellbeing
- 🧠 **Learning** - Knowledge acquisition
- 👨‍👩‍👧‍👦 **Family/Personal** - Relationships
- 💰 **Finance** - Money management
- 🎨 **Creative** - Artistic pursuits
- 🏠 **Home/Life** - Daily living
- 🌱 **Growth** - Personal development

## Color Psychology & Usage

### Primary Color System
- **🔴 Red Family** - Urgency, attention, problems
  - `#ff3838` - Critical/urgent
  - `#ff4757` - High priority
  - `#ff6b6b` - Warning/blocked
  
- **🟠 Orange Family** - Energy, focus, medium priority
  - `#ffa502` - Medium priority
  - `#ff6348` - Energy/enthusiasm
  - `#ff7675` - Warm attention

- **🟡 Yellow Family** - Caution, review, thinking
  - `#ffd32a` - Waiting/review
  - `#f9ca24` - Ideas/brainstorming
  - `#fdcb6e` - Learning/study

- **🟢 Green Family** - Success, growth, completion
  - `#2ed573` - Completed/success
  - `#00b894` - Growth/progress
  - `#55a3ff` - Healthy/stable

- **🔵 Blue Family** - Information, systems, calm
  - `#3742fa` - Projects/structure
  - `#2f3542` - Information/data
  - `#40739e` - Research/analysis

- **🟣 Purple Family** - Creativity, synthesis, advanced
  - `#8c7ae6` - Creative work
  - `#6c5ce7` - Synthesis/connection
  - `#5352ed` - Advanced/expert

### Accessibility Considerations
- **High Contrast**: All icon/color combinations meet WCAG AA standards
- **Pattern Backup**: Icons work without color for colorblind users
- **Semantic Meaning**: Colors reinforce meaning, don't create it
- **Consistency**: Same color always means same thing across system
