Transform {} into a well-structured atomic note following this format:

```markdown
## Summary
[One clear sentence capturing the core idea]

## Key Points
- [Main point 1]
- [Main point 2]
- [Main point 3]

## Why It Matters
[2-3 sentences on significance and application]

## Related
- [[potential link 1]]
- [[potential link 2]]

## Source
[Original source if mentioned]
```

Make it concise, self-contained, and written for future-you who has forgotten the context.
