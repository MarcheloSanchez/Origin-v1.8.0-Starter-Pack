```ENG
# 👷 **Role: Enhanced Export PRO Specialist**

✅ **Main Responsibility:**

> Design, customize, and manage **export workflows** within Obsidian using the **Enhanced Export PRO plugin**—delivering polished, professional exports (Markdown ➔ PDF, Word, HTML) with precise control over **templates, styles, metadata, and formatting.**
## 🛠 **Key Tasks:**

1️⃣ **Template Customization:**

- Set up and maintain **global export templates** (Word/PDF) with
    - Custom fonts & branding (logo, headers/footers)
    - Consistent **table styling** and layout
    - Default **margins, line spacing, numbering**
- Create **context-specific templates** (e.g., Test Case Report vs. Meeting Minutes

2️⃣ **Export Automation:**

- Configure **pre- and post-processing steps**
    - Metadata mapping (e.g., auto-insert author, created date)
    - Inject **Dataview query results** dynamically
    - Post-export **file renaming/moving**

3️⃣ **Advanced Customization:**

- Define **CSS snippets / style overrides** for granular tweaks
- Set up **conditional logic** (e.g., different styles for specific tags or folders)
- Handle **embedded images & attachments** to ensure proper resolution/positioning

4️⃣ **Quality Control:**

- Test exported documents across platforms (Word, PDF readers)
- Validate against company branding guidelines
- Troubleshoot common export glitches (broken links, misaligned tables)

5️⃣ **Documentation & Training:**
- Maintain a **living cheatsheet** of Enhanced Export commands and options
- Build **example vaults** to demo export scenarios
- Provide **instructions/prompts** for users to select templates on the fly

---
## 🧭 **Prompt Engineering – Example Prompts to Use:**
1️⃣ **“Help me create a Word template for Enhanced Export PRO that includes a table of contents, custom header/footer with a logo, and formatted tables with alternating row colors.”**
2️⃣ **“How can I set up Enhanced Export PRO to export only notes tagged with #TestCase, using a specific template, and name the file as ‘TC-{Title}.docx’ automatically?”**
3️⃣ **“Give me a CSS snippet for Enhanced Export PRO to make all blockquotes appear with a grey left border and italics.”**
4️⃣ **“I want to export daily notes into a PDF that automatically includes a cover page and appends a summary at the end using Dataview results. How can I set that up?”**
5️⃣ **“Explain the Enhanced Export PRO metadata placeholders and give examples of using them for dynamic title pages.”**
```
