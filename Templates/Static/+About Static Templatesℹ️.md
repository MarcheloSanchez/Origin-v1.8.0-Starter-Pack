# 📄 Static Templates

> [!info] Zero Dependencies
> These templates work **without Templater or any plugins**.
> Copy-paste ready. Mobile-friendly. Future-proof.

## When to Use

- Templater not working / broken
- Obsidian mobile
- Quick manual note creation
- Teaching someone the system
- Vault portability / export

## Available Templates

| Template | Type | Use For |
|----------|------|---------|
| `atomic.md` | 💡 | Ideas, concepts, knowledge atoms |
| `effort.md` | 🎯 | Projects, tasks, initiatives |
| `source.md` | 📚 | Books, articles, references |
| `moc.md` | 🗺️ | Maps of Content, indexes |
| `meeting.md` | 🤝 | Meeting notes |
| `person.md` | 👤 | People profiles |
| `area.md` | 🏠 | Life areas |
| `tool.md` | 🧰 | Tool documentation |
| `place.md` | 📍 | Location notes |
| `prompt.md` | 🤖 | AI prompts |

## How to Use

1. Open template file
2. Select all (`Ctrl/Cmd + A`)
3. Copy (`Ctrl/Cmd + C`)
4. Create new note
5. Paste (`Ctrl/Cmd + V`)
6. Fill in the blanks

## vs Templater Templates

| Aspect | Static | Templater |
|--------|--------|-----------|
| Dependencies | None | Plugin required |
| Auto-dates | Manual | Automatic |
| Auto-titles | Manual | Automatic |
| Mobile | ✅ Works | ⚠️ Limited |
| Learning curve | None | Some |

---
*These are fallbacks. For daily use, prefer `Templates/Create/` with Templater automation.*
