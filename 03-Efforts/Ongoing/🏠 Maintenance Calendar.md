# 🏠 Maintenance Calendar & Schedule

Complete system of what to maintain, when, and why. Use this to prevent emergencies and plan major tasks.

---

## 📅 WEEKLY ROTATION

### Standard Weekly Schedule (Repeating)

```
MONDAY    → Kitchen Weekly Deep
TUESDAY   → Bathroom Weekly Deep
WEDNESDAY → Bedroom Weekly Deep
THURSDAY  → Living Areas Weekly Deep
FRIDAY    → Entry & Laundry Weekly Deep
SAT-SUN   → Off / Catch-up if needed
```

**Daily**: All rooms get basic routine (5-15 min total)

---

## 🗓️ MONTHLY ROTATION

### Deep-Clean by Month

One room gets the full monthly treatment each week:

**Week 1**: Kitchen Monthly Deep-Clean
- Fridge interior organization
- Cabinet inspection
- Appliance coils
- Behind refrigerator

**Week 2**: Bathroom Monthly Deep-Clean
- Grout scrubbing
- Under-sink organization
- Exhaust fan check
- Caulk inspection

**Week 3**: Bedroom Monthly Deep-Clean
- Mattress flip/rotate
- Closet organization
- Dust high surfaces
- Under-bed clean

**Week 4**: Living Area Monthly Deep-Clean
- Move furniture (vacuum underneath)
- Furniture rotation if desired
- Baseboards deep dust
- Light fixture cleaning

## 🔄 QUARTERLY MAINTENANCE (Every 3 Months)

Bigger tasks that prevent future problems. Do ONE each quarter (spread out).

### **Q1: January - March (Winter → Spring)**

**January Focus: Kitchen Storage**
- [ ] Pantry organization & expiration check
- [ ] Fridge deep clean & sanitize
- [ ] Freezer inventory
- [ ] Kitchen cabinets audit

**February Focus: Bedroom Refresh**
- [ ] Closet overhaul (donate unused)
- [ ] Wash all bedding including mattress cover
- [ ] Dust ceiling fan thoroughly
- [ ] Windows inside & outside (if accessible)

**March Focus: Bathroom Systems**
- [ ] Shower/tub deep clean with vinegar
- [ ] Check for mold/mildew (address if found)
- [ ] Exhaust fan cleaning (remove cover, blow out dust)
- [ ] Grout sealing inspection (hire if needed)

### **Q2: April - June (Spring → Summer)**

**April Focus: Living Areas Refresh**
- [ ] Move furniture, deep clean underneath
- [ ] Wash windows thoroughly (inside & outside)
- [ ] Dust ceiling fans, vents, light fixtures
- [ ] Clean/organize shelving

**May Focus: Entry & Exterior**
- [ ] Sweep & mop entry thoroughly
- [ ] Check door seals for wear
- [ ] Wipe down entryway walls
- [ ] Organize coat closet (prepare for seasonal storage)

**June Focus: HVAC Preparation**
- [ ] Change AC filter (if applicable)
- [ ] Check that AC is functioning properly
- [ ] Dust any return air vents
- [ ] Plan any AC service needed

### **Q3: July - September (Summer → Fall)**

**July Focus: Deep Kitchen Clean**
- [ ] Clean inside oven (or hire if needed)
- [ ] Wipe inside all cabinets
- [ ] Organize drawers (utensils, gadgets)
- [ ] Check for pest evidence

**August Focus: Laundry & Wash**
- [ ] Wash all blankets/comforters
- [ ] Clean inside washer (run empty cycle with vinegar)
- [ ] Clean dryer interior (beyond lint trap)
- [ ] Check hoses for wear

**September Focus: Prepare for Fall**
- [ ] Check weatherstripping on windows/doors
- [ ] Verify heat is functioning
- [ ] Clean gutters if accessible (or hire)
- [ ] Inspect basement/storage areas

### **Q4: October - December (Fall → Winter)**

**October Focus: Deep Bathroom Clean**
- [ ] Caulk inspection & replacement if needed
- [ ] Tile grout deep clean
- [ ] Under-sink inspection for leaks
- [ ] Water pressure check

**November Focus: Holiday Preparation**
- [ ] Deep clean guest areas (if hosting)
- [ ] Organize entry for seasonal decorating
- [ ] Check storage for holiday items
- [ ] Dust & refresh main living areas

**December Focus: Year-End Systems**
- [ ] Organize under-bed storage
- [ ] Donate/declutter items from year
- [ ] Plan new storage systems for new year
- [ ] Deep kitchen clean for holidays

## 🔧 ANNUAL MAINTENANCE (Once per Year)

Major preventive tasks. Schedule these specifically to prevent emergencies.

### Spring (March-April)
- [ ] **HVAC Service** - AC check before summer (professional)
- [ ] **Water Heater Check** - Inspect for leaks, efficiency
- [ ] **Plumbing Inspection** - Check for slow drains, leaks
- [ ] **Gutter Cleaning** - Prepare for spring rains (DIY or professional)

### Fall (September-October)
- [ ] **HVAC Service** - Heating check before winter (professional)
- [ ] **Furnace Filter Change** - Stock extras for winter
- [ ] **Weatherstripping Check** - Prepare for temperature changes
- [ ] **Fireplace/Chimney** - If applicable, professional cleaning

### Year-Round
- [ ] **Pest Control** - Professional inspection (1-2x yearly)
- [ ] **Roof Inspection** - After major storms, 1x yearly minimum
- [ ] **Foundation Check** - Look for cracks, settling
- [ ] **Paint Touch-ups** - Note needed touch-ups throughout year

## 🚨 Emergency Maintenance Trigger List

If ANY of these occur, address IMMEDIATELY:

- [ ] Water leaks (slow drip or active leak)
- [ ] Mold/mildew evidence (especially bathroom/basement)
- [ ] Pest sighting or evidence
- [ ] Unusual smells (gas, sewer, burning)
- [ ] Appliance malfunction (fridge, washer, dryer)
- [ ] Electrical issues (sparking, burning smell, breaker trips)
- [ ] HVAC not working (heating or cooling)
- [ ] Plumbing issues (slow drain, backed up toilet, no hot water)
- [ ] Visible structural damage (cracks in walls, ceiling)

**Action**: If urgent (water, gas, electrical, fire), call professional same day

## 💰 Financial Impact: Why Preventive Maintenance Saves Money

### Reactive (Emergency) Maintenance vs Preventive

| Issue | Emergency Cost | Preventive Cost | Savings |
|-------|-----------------|-----------------|---------|
| AC breakdown | $1000+ replacement | $150/yr service | $850+ |
| Mold in bathroom | $2000-5000 remediation | $10 grout sealer | $1990+ |
| Clogged drain | $300 snake service | $0 (preventive care) | $300 |
| Washer breakdown | $600 replacement | $50/yr maintenance | $550 |
| Gutter damage | $1000 repair | $100 cleaning/yr | $900 |

**Total 1-Year Preventive Investment**: ~$400
**Average 1-Year Emergency Cost**: ~$1500+
**ROI**: 3.75x savings through prevention
