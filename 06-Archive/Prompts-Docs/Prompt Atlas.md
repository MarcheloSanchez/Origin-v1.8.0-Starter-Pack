# 🔎 What is a “Prompt Atlas”?
In PKM vocabulary, an **Atlas** (or MOC – Map of Content) is like a **navigation hub**.  
Instead of raw Dataview queries, it’s a **curated note** where you manually (or semi-automatically) link to important items, grouped by meaning.

Example difference:
- Dashboard shows _all_ “Education” prompts sorted by date.
- Atlas shows:
    - “Teaching Tools → edu-quiz-builder-5q”
    - “Study Aids → edu-flashcard-generator”
    - …with your notes (“I use this in weekly study planning”).
So: Atlas = **map**, Dashboard = **control panel**.
