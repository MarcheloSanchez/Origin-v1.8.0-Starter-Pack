# Network Effects

> [!orbit] Tutorial Example
> This note was synthesized during MOC creation (Day 6).

---

## One-liner

The value of a network increases **exponentially** with each new node added. More connections = disproportionately more value.

---

## The Math

Metcalfe's Law: Network value ≈ n²

| Nodes | Potential Connections | Value Multiplier |
|-------|----------------------|------------------|
| 2 | 1 | 1x |
| 10 | 45 | 45x |
| 100 | 4,950 | 4,950x |
| 1,000 | 499,500 | 499,500x |

Adding node #100 adds 99 new potential connections. Adding node #1,000 adds 999.

---

## In PKM Context

Each new note doesn't just add 1 unit of value. It adds potential connections to EVERY existing note.

```
Note #1:   Value = 1
Note #10:  Value = 1 + potential links to 9 others
Note #100: Value = 1 + potential links to 99 others
```

This is why older vaults become more valuable over time - not linearly, but exponentially.

---

## Why Linking Matters

An unlinked note is a node with no connections. Its network value = 0.

A well-linked note multiplies the value of the entire vault.

> "Every link you make pays dividends forever."

---

## Examples

| System | Network Effect |
|--------|----------------|
| **PKM vault** | More notes → more possible connections |
| **Social network** | More users → more reasons to join |
| **Forest ecosystem** | More trees → stronger mycelium network |
| **Language** | More speakers → more useful to learn |
