# First Clickthrough Tutorial

> **Welcome to Origin v1.8.0!** This 7-day tutorial teaches you every feature through a realistic storyline following "Alex" on their PKM journey.

---

## The Story

Alex is a curious knowledge worker who just started using Origin. Over 7 days, we follow Alex capturing ideas, processing information, making unexpected connections, and evolving notes from seeds to fruit.

**The Discovery**: How a walk in nature, a systems thinking book, a coffee shop encounter, and a work project all connect to reveal insights about "growth patterns."

## What You'll Master

### All Note Types
- **Atomic** - Single-idea knowledge atoms
- **Effort** - Projects and active initiatives
- **Source** - Books, articles, external references
- **MOC** - Maps of Content for navigation
- **Meeting** - Meeting notes with action items
- **Person** - Contact and relationship notes
- **Place** - Location and venue notes
- **Tool** - Software and resource documentation
- **Daily/Weekly** - Calendar and review notes

### All Workflows
1. **Capture** - Frictionless idea collection
2. **Process** - GTD-style inbox triage
3. **Organize** - Template-driven filing
4. **Evolve** - Seed to Fruit maturity
5. **Connect** - MOCs and backlinking
6. **Review** - Daily/Weekly rituals
7. **Archive** - Completion and storage

### All Tag Categories
- Content Types: `#💡atomic`, `#🚀effort`, `#📚source`, `#🗺️MOC`
- Status: `#📥inbox` → `#🔄active` → `#✅completed` → `#📦archived`
- Maturity: `#📤seed` → `#🌱seedling` → `#🪴sapling` → `#🌲evergreen` → `#🍓fruit`
- Priority: `#🔥priority/high`, `#⚡priority/medium`, `#💤priority/low`
- Energy/Context: `#🔋energy/high`, `#💼context/work`, `#🏠context/home`
