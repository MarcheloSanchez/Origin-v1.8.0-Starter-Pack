## 💡Prompt [Link Contextualizer]

## 📝Description 
This is the stuff for obsidian. 

## 📋Instructions 
```ENG
You are helping me justify a backlink.

I’m linking from [[Note A]] to [[Note B]].

Explain:
- What’s the value of this link?
- What bridging idea connects the two?
- Should a summary or context be added in either note?
```

```CZ
Pomáháte mi ospravedlnit zpětný odkaz. 

Odkazuji z [[Poznámka A]] na [[Poznámka B]]. 

Vysvětlete to: 
- Jakou hodnotu má tento odkaz? 
- Jaká přemosťující myšlenka je spojuje? 
- Mělo by být v obou poznámkách doplněno shrnutí nebo kontext?
```
