## What It Does

Excalidraw is a hand-drawn style whiteboarding tool embedded directly in Obsidian. Perfect for:

- Mapping connections between notes visually
- Brainstorming and mind mapping
- Creating diagrams for documentation
- Sketching workflows and processes

---

## Why I Use It

1. **Embedded in vault**: Drawings live alongside notes
2. **Wikilinks work**: Link to notes from within drawings
3. **Hand-drawn aesthetic**: Feels natural, less formal
4. **Export options**: PNG, SVG for sharing

---

## Key Features

### Drawing Tools
- Shapes, arrows, text
- Freehand drawing
- Library of common elements

### Obsidian Integration
- `[[Wikilinks]]` work inside drawings
- Embed drawings in regular notes
- Backlinks from drawings

### Collaboration
- Export and share drawings
- Import others' drawings

---

## My Workflows

### 1. Connection Mapping
When I have 3+ notes on a topic, I create an Excalidraw diagram showing how they connect.

### 2. Brainstorming
Quick sketches for new ideas before they become formal notes.

### 3. Visual MOCs
Some MOCs work better as diagrams than text lists.

---

## Tips & Tricks

- Use `Ctrl+K` to insert wikilinks in text elements
- Hold Shift for straight lines
- Double-click canvas for quick text
- Use library for reusable elements
