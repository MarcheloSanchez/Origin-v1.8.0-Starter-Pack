# 🏷️ GTD Contexts Guide

> Kontexty ti pomáhají filtrovat úkoly podle toho, **kde jsi** a **co máš k dispozici**.

---

## 📍 Základní kontexty

| Context | Kdy použít | Příklady |
|---------|------------|----------|
| `@computer` | Potřebuji počítač | Napsat email, programovat, research |
| `@home` | Musím být doma | Úklid, vaření, domácí projekty |
| `@work` | Musím být v práci | Meetings, office tasks |
| `@phone` | Potřebuji telefon | Zavolat, SMS, mobilní app |
| `@errands` | Venku, pochůzky | Nákupy, pošta, úřady |
| `@people` | Potřebuji někoho | Diskuse, spolupráce |
| `@waiting` | Čekám na někoho | Delegované, odpovědi |
| `@anywhere` | Kdekoliv | Čtení, brainstorming |

---

## ⚡ Energy kontexty

| Tag | Energy Level | Kdy použít |
|-----|--------------|------------|
| `⚡` | High | Komplexní práce, kreativita, rozhodování |
| `🔋` | Medium | Běžné úkoly, komunikace |
| `🪫` | Low | Rutina, administrativa, třídění |

---

## 📅 Time kontexty

| Tag | Význam |
|-----|--------|
| `📅 YYYY-MM-DD` | Due date |
| `⏰ 15min` | Krátký úkol |
| `⏰ 1h` | Střední úkol |
| `⏰ 2h+` | Dlouhý úkol (naplánuj blok) |

---

## 🎯 Priority

| Tag | Význam | Použití |
|-----|--------|---------|
| `🔴` nebo `high` | Kritické | Musí být dnes/zítra |
| `🟡` nebo `medium` | Důležité | Tento týden |
| `🟢` nebo `low` | Nice to have | Když je čas |

---

## 📝 Jak psát Next Actions

### ✅ Správně (konkrétní, proveditelné)
```
- [ ] @computer Napsat odpověď Petrovi na email o projektu X
- [ ] @phone Zavolat doktorovi a objednat se
- [ ] @errands Koupit mléko v Albertu
- [ ] @work Zeptat se šéfa na deadline projektu Y
```

### ❌ Špatně (vágní, není jasné co dělat)
```
- [ ] Projekt X
- [ ] Zdraví
- [ ] Nakoupit
- [ ] Práce
```

---

## 🔄 Workflow

```
1. CAPTURE - Zachyť myšlenku do Inbox
2. CLARIFY - Co to je? Je to actionable?
   └── NE → Reference / Someday / Trash
   └── ANO → Definuj next action
3. ORGANIZE - Přidej kontext, prioritu, deadline
4. REFLECT - Weekly review
5. ENGAGE - Vyber podle kontextu a energie
```

---

## 🧠 Tips

1. **2-minute rule**: Trvá to < 2 min? Udělej hned.
2. **One context per task**: Vyber hlavní kontext
3. **Verb first**: Začni slovesem (Napsat, Zavolat, Koupit...)
4. **Be specific**: "Koupit mléko" ne "Nakoupit"
5. **Review regularly**: Kontexty se mění

## ⌨️ Quick Add Syntax

```markdown
- [ ] Task description @context ⚡ 📅 2026-01-15
```

```markdown
- [ ] Napsat report pro šéfa @work ⚡ 📅 2026-01-10

- [ ] Koupit dárky @errands 🪫 📅 2026-01-20
- [ ] @waiting Odpověď od klienta na nabídku
```
