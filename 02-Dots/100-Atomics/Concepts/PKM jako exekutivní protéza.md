## 🧠 One-liner
PKM systém (osobní knowledge management) funguje jako "exekutivní protéza" pro ADHD mozek — externalizuje working memory, prioritizaci a self-monitoring tam, kde mozek selhává.

## 🧩 Notes & Sketches

### PKM → Exekutivní funkce mapping
| EF deficit | PKM řešení | Origin vault implementace |
|---|---|---|
| **Working memory** | External brain — vše zapsáno | Atomic notes, wiki-linky, related pole |
| **Prioritizace** | Status/priority systém | `priority: high/medium/low`, `processing_priority` |
| **Iniciace** | Quick-capture snižuje bariéru | `+Inbox`, quick-process skripty, gamifikace (XP) |
| **Plánování** | Effort templates + review | 03-Efforts, weekly/monthly review |
| **Self-monitoring** | Dashboard + metriky | `👁️Dashboard.md`, `_Metrics Cache.md`, weekly report |
| **Emoční regulace** | Journaling, tracking | Daily notes, mood/energy fields |
| **Sustained attention** | Atomic notes = malé kousky | Jedna myšlenka = jedna note (ne 10-stránkový dokument) |

### Proč Origin vault je "ADHD-native"
1. **Gamifikace = dopaminový scaffolding** — XP, streak, levely nahrazují chybějící vnitřní motivaci
2. **Atomic notes = low activation energy** — malá note je snadnější začít než velký dokument
3. **Templates = reduced decisions** — šablona rozhodne za tebe (decision fatigue killer)
4. **Status workflow = external accountability** — `📥inbox → 🔄active → ✅completed` je viditelný progress
5. **Review systém = forced reflection** — ADHD mozek nereflektuje spontánně, potřebuje trigger
6. **Wiki-linky = asociativní myšlení** — ADHD mozek myslí v asociacích, ne lineárně — PKM to podporuje!

### Rizika
- **Productivity porn**: nekonečné ladění systému místo tvorby obsahu
- **Přesystematizování**: příliš mnoho polí/procesů → exekutivní přetížení
- **Perfekcionismus**: "musím zpracovat vše" → paralýza
- **Náhrada za terapii**: PKM kompenzuje, ale neléčí
