# Surfacing — Signal Design

Concise titles, explicit job-like statements, and a small set of consistent tags act as discovery signals that increase the chance a note resurfaces.

Key points:
- Title should contain intent or context (e.g., "When commuting — productivity rituals").
- Add 1–2 persistent tags (area + method) rather than many ephemeral tags.
- Frontmatter fields like `maturity`, `MOC`, and `related` enable dashboard queries and connection detection.
