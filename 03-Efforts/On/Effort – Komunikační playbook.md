# Project: Effort – Komunikační playbook

## 🎯 Objective - Goal
**What**: Vytvořit praktickou sbírku komunikačních technik, frameworků a checklistů
**Why**: Přejít od teorie k praxi — mít po ruce konkrétní nástroje pro různé situace
**Success looks like**: 5+ playbook notes + osobní zkušenosti zaznamenané v daily notes

## 📋 Scope & Requirements
### Must Have
- Playbook: Aktivní naslouchání (✅ hotovo — HEAR framework)
- Playbook: NVC v praxi — rozšířit příklady
- Playbook: Vyjednávání — BATNA, Harvard principy
- Playbook: Feedback giving/receiving
- Playbook: Těžké konverzace (difficult conversations)

### Nice to Have
- Playbook: Prezentační skills + storytelling
- Playbook: Networking pro introverty/AuDHD
- Propojit s řečí těla — neverbální checklist pro každou situaci
- Tracking: 1 komunikační experiment týdně v daily notes

## 🗺️ Action Plan
### Phase 1: Foundation ✅
- [x] Vytvořit MOC - Komunikace a MOC - Řeč těla
- [x] Seed notes pro klíčové koncepty (12 notes)
- [x] Source notes (Rosenberg, Cialdini)
- [x] Playbook — Aktivní naslouchání checklist

### Phase 2: Core Playbooks (aktuální)
- [ ] Rozšířit NVC playbook — více situací, emoční kolo
- [ ] Vytvořit Playbook — Vyjednávání (BATNA + principled negotiation)
- [ ] Vytvořit Playbook — Feedback framework (SBI model)
- [ ] Vytvořit Playbook — Těžké konverzace (DEAR MAN z DBT)

### Phase 3: Integration & Practice
- [ ] Přidat weekly communication experiment do review
- [ ] Propojit playbooks s řečí těla (neverbální tipy ke každému)
- [ ] Zaznamenat 10+ osobních zkušeností
- [ ] Vytvořit "quick reference card" — 1 stránka s klíčovými frameworky
