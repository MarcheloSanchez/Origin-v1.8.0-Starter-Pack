# Failures & Anti-Patterns
- Overbroad roles → mushy outputs
- No output schema → impossible evals
- Too many instructions → model ignores late ones
- Missing counterexamples → brittle performance
- Leaking abbreviations without expansion → reader confusion

For each failure, link to example experiment and the fixed prompt.
