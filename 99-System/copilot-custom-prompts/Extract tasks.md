Transform {} into clear, actionable tasks. For each task identified:

- [ ] **Task**: Clear action verb + specific outcome
  - **Context**: Where/when to do this
  - **Energy**: high/medium/low required
  - **Time estimate**: How long it takes
  - **Dependencies**: What needs to happen first

Group tasks by:
1. **Quick wins** (< 5 minutes)
2. **Focus work** (requires deep concentration)
3. **Waiting on** (blocked by external factors)

Use GTD principles: tasks should be concrete next actions, not vague projects.
